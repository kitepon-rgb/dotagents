# Orchestrate — 統括の標準型

**中核思想: 品質は「モデルの賢さ」ではなく「構造」から出す。** 並列多視点・敵対的検証・安全網・委譲契約という構造が本体であり、統括モデルが替わっても構造は再現できる。統括（このセッションの主モデル）は裁定・契約クリティカル・ゲートに知能を集中し、物量は安価な知能に配る。

## 憲法（7カ条・違反したら立ち止まる）

1. **安全網先行**: ベースラインのゲートを green にしてから触る。リファクタは「触る契約」限定の characterization を先に張る（実物依存で。フェイクDB等は偽の安心）。CI が無ければ最初に張る。
2. **敵対的検証**: 重要な指摘・計画は、独立の反証者に「殺させて」生き残ったものだけ採用する。もっともらしい大改造ほど反証にかける（実績: 確定71/棄却21＝棄却側に危険な良案が複数いた）。
3. **委譲契約**: 委譲は必ず `references/delegation-contract.md` の8点セットで。特に「渡した前提も再検証せよ」を省くと、上流の誤りが素通りする（委譲先が監査の誤りを3回正した実績）。
4. **統括ゲート**: 委譲物は diff レビュー＋ゲート自分で再実行してから採用。鵜呑みも盲目的却下もしない。
5. **レーン分離**: 挙動不変レーンと挙動修正レーンを分け、後者は1件ごとに挙動差を明文化して個別承認。
6. **独立完結の刻み**: どの時点で止めても価値が完結する単位で刻み、各単位でフルゲート→pathspec 明示コミット。
7. **知識の還流**: 学びは即座に memory（プロジェクト事実）/ caveat（外部仕様の罠）/ rag（外部調査）へ。セッションと共に蒸発させない。

## 知能の配置

| 層 | 担当 | 実行手段 | モデル |
|---|---|---|---|
| L0 統括 | 裁定・契約クリティカル（認可/tx/公開API互換/依存方向/本番操作）・履歴修復・コミット・最終責任 | 本人 | セッション主モデル |
| L1 監査・検証 | 発見→重複統合→**指摘ごとの反証**→網羅性Critic（盲点→第2ラウンド） | Workflow（`references/workflow-templates.md`） | 省略=主モデル継承（検証の精度優先）。数で押す finder は sonnet 可 |
| L2 設計 | 2〜4視点の並列設計（実行順序/配置/取捨 等）→**割れは統括が根拠で裁定**（多数決禁止） | Agent (Plan) | 主モデル継承 |
| L3 実装 | 仕様が固まった実装・テスト作成・逐語移設・整理 | Agent/Workflow `model: sonnet`（機械的なら haiku） | sonnet 既定 |
| L4 外部CLI | 完全固定仕様の機械的一括・第三者視点レビュー | `codex exec/review`・`grok --check/--best-of-n`（永続PTY駆動） | — |

**波の設計**: 並列は非交差ディレクトリで割る。同一ファイルを触る作業は直列化（wave 分け）。エージェントに branch 切替・commit をさせない。

## フェーズ・パイプライン

```
0 ベースライン   ゲート実行→green 確認（赤なら環境/テストを先に根治）
1 監査/発見     L1 audit workflow → 確定/棄却/盲点（盲点は第2ラウンド）
2 設計         L2 複数視点 → 統括裁定 → 計画に「やらない表」＋罠リスト＋検証方法を必ず含める
3 安全網       characterization（触る契約限定・実物依存）＋CI。ここまで本体に触らない
4 実装         L3 波状委譲 → 統括レビュー → ゲート → pathspec コミット（波ごと）
5 挙動修正     承認済みレーンのみ。1件=挙動差明文
6 統合/運用    push→CI green 確認→（指示があれば）デプロイ＝検証バッテリー付き → 知識還流
```

## アンチパターン（実被弾済み）

- 反証なしで監査結果を実装へ（→ 危険な大改造が混入する）
- 裸の `git commit`（→ 並行エージェントの staged 変更を巻き込む。pathspec 明示）
- 安全網より先に本体を触る／ベースライン赤のまま着手
- 委譲仕様に再検証義務・罠リスト・合格条件を書かない（→ 品質はモデルでなく仕様で死ぬ）
- 1体に巨大タスク（→ 分解して波状に。1体=1責務=1レビュー単位）
- エージェントの「できました」を鵜呑み（→ ゲートは統括が回す）

## 標準エージェント（~/.claude/agents に定義済み）

- **implementer**（sonnet）: 委譲契約を焼き込んだ標準実装者。契約の共通部を毎回書かなくてよい。
- **refuter**（主モデル継承・読み取り専用）: 敵対的検証者。指摘/計画/主張を実ファイルを読んで殺しにかかる。
