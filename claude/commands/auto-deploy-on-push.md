---
description: GitHub への push を契機に自宅サーバへ自動 docker compose デプロイするワークフローを構築する
---

スキル `auto-deploy-on-push` (`~/.claude/skills/auto-deploy-on-push/SKILL.md`) を読み込み、その手順に従って現在のプロジェクトに自動デプロイを実装する。

引数があれば対象プロジェクトのパスとして扱う。引数が無ければ現在の作業ディレクトリを対象とする。

進め方:
1. スキル本文を Read で読み、6 ステップの手順を頭に入れる
2. 「適用条件チェック」を全項目走らせる。一つでも × なら、スキル末尾「変種」を提示してユーザー判断を仰ぐ
3. 全部 ✓ なら 1 → 6 まで順に実装
4. 完了基準（main へ push して数分以内に新コードが本番で起動）を最後に確認する
